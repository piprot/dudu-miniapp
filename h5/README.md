# H5 版（公众号投放用）

把小程序里「朋友圈文案生成」这一步**外迁到网页**，链接放到公众号文章 / 菜单 / 阅读原文里。
另有一页 **定制样板间**（`comic.html`），用来展示成品、收定制需求。

**为什么要有这个**：个人主体小程序拿不到「深度合成」类目（AI 问答 / AI 绘画 / AI 换脸等一律不在个人主体可选清单内），
所以 AI 生成能力留在小程序里提审必然被拒。H5 是官方口径下个人主体可用的落点 —— 能力不变，载体换掉。
小程序端继续提供**不需要 AI 生成**的功能（成品示例、阅读、付费定制入口）。

> ⚠️ 换载体**不豁免法律义务**。页面上常驻「AI 生成」提示标识、底部使用说明与免责声明，
> 都是《人工智能生成合成内容标识办法》《生成式人工智能服务管理暂行办法》要求的内容，**不要删**。

## 两个页面，两种角色

| 页面 | 角色 | 能不能生成内容 |
|---|---|---|
| `index.html` | **免费钩子** —— 朋友圈文案工具，收日额度限流的免费用户 | ✅ 能（走 `ai_gen` 的 H5 通道） |
| `comic.html` | **成交页** —— 成品样板间 + 需求提交，¥66/¥88 定制 | ⛔ **绝不能**（见下） |

### comic.html 为什么不开放自助生成（合规红线，勿破）

想让客户「输入自己的故事 → 立刻看到自己的连环画」，那是**提供深度合成服务**，
必须**以企业主体做算法备案**（个体户与个人无法独立备案），而本仓库是个人主体。

所以样板间走的是另一条路 —— **只卖已完成的成品内容**：

```
H5 展示成品样例 → 客户提交需求（只落库）→ 引导进小程序下单 → 我们制作好发到邮箱
```

客户在 H5 上看不到任何「生成」按钮，H5 也不调用任何出图接口。
这样性质就是**卖内容成品**，不是**提供合成服务能力**，不需要备案。
付款复用小程序已有的个人虚拟支付（`comic_pdf` ¥66 / `comic_web` ¥88），零新增成本。

> 一旦有人在 `comic.html` / `comic.js` 里接上出图模型，性质立刻改变。
> `test/test_h5_comic.js` 第 6/7/9/10 条会拦这个 —— 别绕过它。

## 部署（四步）

### 1. 打开云函数的 HTTP 入口

微信云开发控制台 → 选中环境 `cloudbase-d8ge1hu2324c8fcdf` → 左侧 **HTTP 访问服务** → 添加路径：

| 路径 | 指向 | 说明 |
|---|---|---|
| `/h5api` | 云函数 `ai_gen` | 就是现有那个云函数，已内置 H5 通道，**不需要新建函数** |
| `/h5req` | 云函数 `h5_request` | 定制需求提交（**新建**，只落库 + 通知，不生成内容） |

保存后会得到一个访问域名，形如：

```
https://cloudbase-d8ge1hu2324c8fcdf.service.tcloudbase.com
```

> 域名以控制台**实际显示**的为准 —— 不同批次环境会带随机后缀。
> 同时确认该环境已把 `ai_gen`、`h5_request` 重新部署（含本次改动），否则对应的通道还不存在。
> ⚠️ HTTP 访问服务**只能在控制台手工配**，CLI 做不到（`cli.bat cloud` 无 service 子命令，`tcb` 会报
> `DescribeCloudBaseGWAPI service evil`）。这一步必须人工点。

### 2. 部署 h5_request 与建集合

1. 右键 `cloudfunctions/h5_request` →「上传并部署：云端安装依赖」。
2. 建两个集合：`h5_requests`（线索）、`h5_req_usage`（限流计数）。
3. （可选）配环境变量，把线索推到飞书 —— 与 `custom_request` **同名同义**：
   `FEISHU_APP_ID` / `FEISHU_APP_SECRET` / `FEISHU_CHAT_ID`。
   **微信云函数的环境变量按函数隔离**，`custom_request` 配过的这里要再配一次。
   不配也能跑（只落库、不推送，线索不会丢）。
4. 自检推送链路：

   ```bash
   curl -X POST "https://<你的域名>/h5req" -H "Content-Type: application/json" \
     -d '{"action":"test_notify"}'
   ```

   返回 `{"ok":true,"configured":true}` 即表示出网与推送都通。

### 3. 把域名填进配置

改 `h5/assets/config.js`（**两个页面共用这一份**，不要再往 HTML 里内联）：

```js
window.H5_CONFIG = {
  api:    'https://<你的环境ID>.service.tcloudbase.com/h5api',   // 文案生成
  apiReq: 'https://<你的环境ID>.service.tcloudbase.com/h5req',   // 需求提交
  mpQr:   '',                       // 可选：小程序码图片路径，填了才显示
  mpName: 'dudu画面感内容工具'
};
```

> 小程序码强烈建议配上：样板间有「进小程序下单」的两处引导，
> 没配时只能退化成「在微信里搜索小程序名」。
> 把小程序码图片放到 `h5/assets/` 下，`mpQr` 填 `assets/mp-qr.png` 这样的相对路径即可。

### 4. 放上静态托管

任选其一：

- **微信云开发「静态网站托管」**：控制台上传 `h5/` 目录内容 → 得到 `https://<env>.tcloudbaseapp.com/...`
- **你自己的服务器 / 对象存储 / 任何静态托管**：把 `h5/` 里的文件原样上传即可

## 示例资产怎么来的（别手工改）

`h5/assets/sample/` 不是手放的，由脚本从**权威示例**生成：

```bash
python tools/make_h5_sample.py
```

- 源：`samples/画面感内容_精简版_单文件.html`（10.4MB，54 格内联 base64，用户手工组装的权威版）
- 输出：免费试读 2 集的原画 JPEG（640×640，q74，约 760KB）+ `manifest.js`（结构 + 文字）

**为什么字图分离**：那份 HTML 里画格是 1024×1024 **纯画面**，旁白 / 气泡 / 音效是叠在上面的
**独立 DOM 层**。H5 能跑 CSS，所以正确的还原方式是「原画抽成文件 + 文字抽成数据」，
而不是把字烧进图（会糊、且不可选）。这与另外两个抽图脚本的分工是**故意分开的**：

| 脚本 | 产物 | 给谁用 |
|---|---|---|
| `tools/extract_sample_panels.py` | 只抽 `<img>`，**丢字** | 备用（无字变体） |
| `tools/compose_sample_panels.py` | 用 PIL 把字**烧进**图 | 小程序（不能 web-view，只能原生 `<image>`） |
| `tools/make_h5_sample.py` | 原画 + 文字**分离** | H5（能跑 HTML/CSS） |

想改免费试读几集：改 `make_h5_sample.py` 的 `FREE_EPISODES` 后重跑，并同步
`test/test_h5_comic.js` 第 1 条的断言（`freeEpisodes` 是商业决定，改了要一起改）。

> 锁定分集**不落图**（`art: ''`）—— 避免把付费内容白送出去。测试第 4 条会拦。

## 定制需求是怎么流转的（h5_request）

```
comic.html 表单 → POST /h5req → 校验 → 幂等去重 → 日限流 → 落库 h5_requests
                                                    ↓
                                      推飞书群（可选）→ 返回 6 位取件码
                                                    ↓
                        客户进小程序选档下单，定制页填**同一个邮箱**
                                                    ↓
                        运营按邮箱把「线索」与「订单」对上 → 8 小时内回邮交付
```

**关键设计**：

- 集合**故意与 `custom_comic_requests` 分开**：那边是「已付款订单」，这边是「未付款线索」，
  混在一起会让运营误把未付款的线索当订单去履约。`h5_requests` 里标了 `paid:false` / `status:'lead'`。
- **只收梗概**（20–1500 字），不收全文。全文到小程序付费后再填 —— 那边已有成型且被测过的流程
  （`custom_request`，`STORY_MAX=30000`）。让客户先低门槛留线索，转化更高。
- 限流：设备桶 + IP 桶，各 `H5_REQ_DAILY = 3` 次/天（北京自然日）。计数落 `h5_req_usage`，只存哈希不存原始 IP。
- 幂等：同设备 + 同内容 10 分钟内重复提交 → 返回**原取件码**，不产生第二条线索。
- 落库失败会**退还额度**，不让服务端故障吃掉用户的提交机会。

> ⚠️ 这是**防滥用**，不是安全边界。真被刷的话代价只是少量数据库写入 ——
> 请在云开发控制台设**数据库容量告警**。

## ⚠️ 放到公众号之前必须知道的两件事

### ① 域名要备案

微信内打开网页，**域名未 ICP 备案会被拦截**。而云开发 HTTP 访问服务的**默认域名仅供开发调试**，
官方不建议用于生产（有配额限制，也不能作为公众号的正式挂载域名）。

**正式投放前应当**：准备一个已备案的域名 → 在 CloudBase 控制台把它绑定到 HTTP 访问服务 →
页面里的 `api` 改成这个域名 → 静态页也挂到同域名下（还能顺带免掉跨域）。

### ② 公众号能不能放外链，取决于账号类型

- 已认证**服务号**：可在文章正文插入外链
- **订阅号**：正文不能插外链，可用「阅读原文」、自定义菜单跳转，或直接引导用户复制的短链

## 免费额度与防滥用

H5 没有 openid，所以计费模型整体换成**日额度**（在 `cloudfunctions/ai_gen/index.js` 顶部）：

```js
const H5_FREE_DAILY = 5;   // 每个「桶」每天 5 次，首次与换一批共用
```

- 桶 = **设备标识**（localStorage UUID）+ **客户端 IP**，两桶独立计数，**任一超限即拒** → 清缓存绕不过 IP 桶
- 计数落在 `h5_usage` 集合，`_id = <北京日>_<桶>_<hash>`，按天分区、次日自动重置
- **只存哈希，不存原始 IP**，不记录用户输入内容
- 生成失败（超时 / 上游报错）会**自动退还额度**，不会因服务端故障吃掉用户的次数

> 这是**防滥用**，不是安全边界。真被刷的话，代价是上游 LLM 的调用费 ——
> 请在火山方舟控制台设置**账户级日预算告警**，这是唯一可靠的止损手段。

想改额度：改 `H5_FREE_DAILY` 后重新部署 `ai_gen`。
前端不参与计算（前端只展示服务端回传的 `quota`），改前端没用。

## 本地预览

不需要任何构建工具：

```bash
cd h5
python -m http.server 8080      # 或 npx serve .
```

- 文案工具：<http://localhost:8080/index.html>
- 样板间：<http://localhost:8080/comic.html>

生成 / 提交需要 `assets/config.js` 的地址指向真实服务；只调样式的话直接双击 HTML 也行。

不过要**看真实版面**建议走一层 iframe 截图器（Windows 上 Chrome 窗口有最小宽度限制，
直接 `--window-size=390` 会被抬宽再裁，看着像"右侧被切"，其实页面没问题）：

```bash
python -m http.server 8124 --directory .          # 项目根目录起服务
chrome --headless=new --no-proxy-server --screenshot=out.png --window-size=520,1250 \
  "http://127.0.0.1:8124/tools_local/_h5_comic_shot.html?h=1150&y=0"
```

`tools_local/_h5_comic_shot.html` 支持的参数：

| 参数 | 作用 |
|---|---|
| `h=<px>` | iframe 高度 |
| `y=<px>` | 向上偏移，用来拍中部 / 底部而不必把 iframe 拉很高 |
| `probe=1` | 把内容真实高度写进 title，用 `--dump-dom` 读 → 量高度，别盲猜偏移 |
| `fill=1` | 把需求表单填满（看"填好待提交"态） |
| `mock=1` | stub 掉 `fetch` 并点提交，看"提交成功 + 取件码"态 |
| `probe=1&fill=1&mock=1` | 量**提交后**的高度（提交会隐藏表单、收起一处二维码，页面变矮） |

> ⚠️ Chrome 的 `--screenshot` 在 Windows 上**必须给绝对路径**，相对路径会报
> `Failed to write file ... 系统找不到指定的路径`。
> 本机还常挂着 HTTP 代理（`http_proxy=127.0.0.1:53886`），要把 `127.0.0.1` 排除掉，
> 所以加 `--no-proxy-server`；用 `curl` 探活时加 `--noproxy '*'`。

## 🔒 改动约束

### ① 类型与字数策略：三处必须同改

`KINDS` / `KIND_STRUCT` / `FIELDS` / `BUILD` / `KIND_LEN_FIXED` / `OUT_LEN_TIERS` / `OUT_LEN_FLOOR`
在三个文件里各有一份：

| 文件 | 角色 |
|---|---|
| `pages/gen/gen.js` | 小程序端展示 + 组装 prompt |
| `cloudfunctions/ai_gen/index.js` | **服务端权威**，真正约束模型的字数与结构 |
| `h5/assets/kinds.js` | H5 端展示 + 组装 prompt |

只改一处 → 就会出现「小程序说 100-250 字、网页给 350 字」这类对不上的体感。
`test/test_h5_parity.js` 会逐项做源码级比对，漏改直接测试失败。

### ② 样板间：价格与字数上限也是两处

| 项 | 前端 | 服务端 |
|---|---|---|
| 价格 | `comic.html` / `comic.js` 的档位文案 | `utils/config.js` 的 `COMMISSION.tiers` |
| 梗概长度 | `comic.html` 的 `storyInput maxlength` | `h5_request/index.js` 的 `STORY_MAX` |

`test/test_h5_comic.js` 第 14/17 条会比对这些值 ——
`maxlength` 比服务端大，用户就会被莫名其妙地拒掉。

### ③ 配置只能有一份

`window.H5_CONFIG` 只在 `assets/config.js` 里定义。**不要在 HTML 里再内联一份** ——
改了一处、另一处还指着旧域名，表现是某个页面单独报错。
测试第 16 条会拦。
